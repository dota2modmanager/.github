Dota 2 Mod Manager installs cosmetic mods for Dota 2 from the open D2PFX catalog: hero sets, effects, terrains, HUDs and more. It is free, open source under GPL-3.0, and runs on Windows and Linux.

**[Download for Windows](https://github.com/dota2modmanager/dota2-mod-manager/releases/latest/download/Dota-2-Mod-Manager-Setup.exe)** · [Linux](https://github.com/dota2modmanager/dota2-mod-manager/releases/latest) · [Website](https://dota2modmanager.com) · [Docs](https://dota2modmanager.com/docs/) · [Discord](https://discord.gg/PBvG8D9MxT)

> [!WARNING]
> **Copies of this app are going around.** Renamed builds are handed out and sold as other people's launchers, with no source code and no credit. The real Dota 2 Mod Manager is free, has no paid version and never asks for your Steam login. Do not trust a launcher that shows no source code, names nobody it is built on, wants a subscription or a payment, or makes you sign in. [How to tell the real one](https://dota2modmanager.com/docs/copies/).

The app, the site and the docs all live in [dota2-mod-manager](https://github.com/dota2modmanager/dota2-mod-manager). Write to [hello@dota2modmanager.com](mailto:hello@dota2modmanager.com), or [security@dota2modmanager.com](mailto:security@dota2modmanager.com) for vulnerabilities.
